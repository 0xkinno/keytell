# The moment

**Tolu Adeyemi (fictional)**, research analyst at a crypto fund in Lagos. Monday, 07:40, twenty
minutes before the investment committee. The partner asks one question: "Is anyone actually using
NEAR, or is it bots and airdrop farmers?"

| What is true | Source |
|---|---|
| Daily active accounts can be inflated by scripts that create accounts in bulk | NEAR accounts are cheap to create; implicit accounts need no transaction at all (docs.near.org, account model) |
| Price moves on news and positioning, not usage | Price is a baseline here only (docs/METHOD.md, section 3) |
| NEAR records which kind of key signed every transaction | docs.near.org, access keys: function-call keys "are meant to be shared with applications" |
| A function-call key cannot attach NEAR, so it cannot drain an account | same page |

**What Tolu does today:** screenshots a DAA chart, a price chart and a TVL figure, and says
"activity is up". The committee cannot tell organic use from farming, so the position is sized on
conviction, which is exactly what this track says it will not judge.

**What Keytell gives Tolu:** one page with a claim fixed on chain before the test data, the evidence
for, the evidence against, the SQL behind every chart, a one-command rebuild, a live lookup that
classifies any account's keys, and a one-page memo (Markdown and PDF) with every number linked.

**The human step:** Tolu decides. Keytell never says buy. Tolu signs the memo with a NEP-413 message,
an attestation that the evidence against was read. That signature is the action a person takes.

**Founder stake:** Kinnoski builds on NEAR; Berthright's own crank signs with function-call keys,
which is the signal this thesis counts. No working analyst has reviewed the method yet; if one does,
the scope will be recorded exactly ("reviewed the method", never "endorsed").
